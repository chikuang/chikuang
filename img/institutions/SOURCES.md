# Institution logo sources

These vector logos are reused from Chi-Kuang Yeh's academic website, with their
paths and colors preserved on transparent canvases. The README selects the
matching light or dark variant with a picture element. All logos are 48 px tall;
Georgia State is 68 px wide, and the other three are 108 px wide.

- Georgia State: https://chikuang.github.io/images/institutions/georgia-state-stacked.svg
- Georgia State (dark): https://chikuang.github.io/images/institutions/georgia-state-stacked-dark.svg
- McGill: https://chikuang.github.io/images/institutions/mcgill.svg
- McGill (dark): https://chikuang.github.io/images/institutions/mcgill-dark.svg
- Waterloo: https://chikuang.github.io/images/institutions/waterloo.svg
- Waterloo (dark): https://chikuang.github.io/images/institutions/waterloo-dark.svg
- Victoria: https://chikuang.github.io/images/institutions/uvic-crest.svg
